# ATL v0.5.0 — Adaptive Reasoning Compiler pilot

112 deterministic piecewise-polynomial tasks (32 development, 80 held-out parameter instances; eight query lengths). Each branch is a live chain of 9–18 state-dependent affine/multiplicative operations modulo 97, polynomial degree at most four. No injected dead nodes. A direct scalar evaluator and coefficient propagation are cross-checked on all 97 inputs per task. Generated Horner expression branches are additionally checked in JS; Python conditional syntax itself was not run. 10864 exhaustive input checks; 1120 one-coefficient mutations rejected. Not an external benchmark or independent LLM inference.

## Static benchmark
Verified exact official o200k_base rank file and three golden token sequences via existing adaptive tokenizer. Counts include system instructions, input, canonical output separately, no framing, caching, tools, or hidden reasoning. Query-free arms keep queries in the deterministic caller and send only the chain to the model. They are a different information-flow architecture, not a same-input comparison. All arms produce the same query answers after deterministic expansion. The direct solver can compute the answers with zero model calls; this is a synthetic compression experiment, not evidence that a model is necessary.

The adaptive router uses exact incoming input and instruction counts plus mean canonical output length from four development tasks of each query size. It never reads held-out solutions for routing. adaptive_same restricts candidates to identical input. The test oracle (22454 tokens) is retrospective and not deployable. No actual accuracy or provider usage measured. Polynomial coefficient encoding is a standard method; no scientific novelty claim. Frozen same-generator split, not unseen task family generalization. Reference Python output uses Horner form, not the shortest possible Python program; stronger direct code-copy/solver baselines remain future work. First development run exposed a generator degree-bound bug (addition raises the degree to at least one); fixed before collecting this report. No failed run included.

## Reproduce
```sh
node piecewise/run.mjs /path/to/o200k_base.tiktoken piecewise-report.json
```
Run uses checksum-verified rank data from adaptive/README.md. The benchmark core ran in JS; standalone Node CLI has not been executed here. Report contains frozen development means and held-out per-query-length totals. All fixtures are reproducibly generated by the code.
