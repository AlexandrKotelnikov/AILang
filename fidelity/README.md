# ATL v0.5.2 — Semantic Fidelity Engine pilot

Research question: how often does answer-only evaluation miss a change in the formal meaning of a translated problem? This is a mutation audit, not a model-accuracy measurement.

## Method
120 reproducible templated English problems, 40 each T/F/U, six named Boolean atoms with the mapping supplied. Eight connective templates (implication, only-if, reverse-if, equivalence, XOR, OR, NAND, inclusive unless). Fixed seed 20261125. Consistent premises only. Canonical syntactic formula/query duplicates excluded, not semantic duplicates. Each problem is exhaustively evaluated over all 64 assignments by both direct connective semantics and reference CNF. No model calls. Strict fidelity means equality of complete premise model sets and equality of the query literal in the fixed atom universe; this is a gold-based metric, not a deployment-time verifier. Redundant clauses and reordering are permitted. Natural-language template meaning is assumed according to the explicit controlled-language convention, not independently human-annotated.

For each reference CNF, enumerate individual clause deletions, literal sign flips, cyclic variable replacements and query sign flip. Count only genuinely meaning-changing mutations in the label-only false-acceptance denominator. Contradictory mutants get label I. 120 positive controls (reordering, duplication and tautology insertion) preserve the model sets.

| Mutation | All | Equivalent | Corrupt | Same answer despite corruption |
|---|---:|---:|---:|---:|
| drop_clause | 1096 | 604 | 492 | 385 (78.25%) |
| flip_literal | 1952 | 564 | 1388 | 754 (54.32%) |
| replace_atom | 1952 | 889 | 1063 | 622 (58.51%) |
| flip_query | 120 | 0 | 120 | 40 (33.33%) |
| Total | 5120 | 2057 | 3063 | 1801 (58.80%) |

7,680 direct/CNF truth checks, 480 canonical format roundtrips and 120 positive controls. Mutations are correlated within tasks; percentages are descriptive, not iid statistical estimates or real LLM error rates.

## Static o200k_base costs
Verified official rank SHA-256 and three golden token sequences using adaptive/tokenizer.mjs. Same English input and supplied atom mapping for all modes. Four compilation formats have identical formal meaning, while direct answer-only is a weaker task.

| Mode | System | Input | Canonical output | Total |
|---|---:|---:|---:|---:|
| spaced | 7800 | 20703 | 4193 | 32696 |
| atl | 8280 | 20703 | 3763 | 32746 |
| numeric | 8640 | 20703 | 4623 | 33966 |
| json | 8280 | 20703 | 5526 | 34509 |
| direct | 3480 | 20703 | 120 | 24303 |

ATL output saves 10.26% relative to spaced CNF but increases complete per-task static totals by 0.15%. No API usage, message framing, hidden reasoning, cache, latency, model accuracy or decoder overhead measured. Canonical strings are generated by reference code rather than LLMs.

## Reproduce
```sh
node fidelity/run.mjs /path/to/o200k_base.tiktoken fidelity-report.json
```
The experiment core ran in JS with the checked rank dictionary; standalone Node CLI not independently executed. See report.json for measured results.

## Related work and next gate
FOLIO (Han et al., EMNLP 2024, https://aclanthology.org/2024.emnlp-main.1229/) and LINC (Olausson et al., EMNLP 2023, https://aclanthology.org/2023.emnlp-main.313/) already investigate natural-language logic translation and symbolic reasoning. No novelty claim for semantic equivalence or model checking. Next: freeze external human-authored examples with formal gold references, compare independent model translations under identical natural inputs, jointly score semantic fidelity, answer correctness and actual provider usage. Predeclare margin and paired task-level statistics. No claims about internal reasoning compression yet.
