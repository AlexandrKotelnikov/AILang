# ATL v0.5.1 — Logical Reasoning Engine pilot

120 synthetic Boolean CNF tasks: 30 development and 90 held-out parameter instances (30 each T/F/U). Separate xorshift seeds; shared canonical clause-order and literal-order key prevents duplicate formulas with the same query across and within splits. This does not prevent semantic equivalence or establish unseen-family generalization. The first attempted generator failed an overlap guard and was discarded; the replacement generator produced zero duplicate rejections. No contradictory knowledge bases included.

The query may be a positive or negative literal. T means all satisfying assignments satisfy the query, F means none, U means both exist. Input N:query, followed by OR clauses with adjacent capital letters; ! negates the following literal. Variables are A through the Nth letter. Output status|branchTrue|branchFalse, where w introduces the assignment bit vector in alphabetic order, c introduces comma-separated 1-based indices for an unsatisfiable subset under that branch assumption. The verifier recomputes unsatisfiability, not a resolution-proof checker.

## Static results
Verified official o200k_base rank SHA-256 and three golden vectors using adaptive/tokenizer.mjs. 63,104 enumerated assignments, 480 cross-check/validation operations, 480 rejected certificate mutations (status, malformed witness, invalid index, swapped branches). Canonical outputs are generated by reference solvers, not independent model calls.

ATL packed saves 60.05% vs verbose English certificate, but costs 1.08% more than standard compact CNF with the identical certificate. ATL input alone saves 8.99% relative to compact CNF. Answer-only baselines are explicitly included; they provide less verification information. Same-input natural_packed reduces canonical output compared with English, but extra system instructions offset much of the benefit. No API framing, cache, tools, latency or hidden reasoning measured.

Hypothetical amortization: if the system prompt is charged once rather than once per task, CNF packed totals 10141, ATL packed 9375. This is arithmetic on existing counts, not an actual batch inference result; delimiters and framing are omitted.

## Reproduce

```sh
node logic/run.mjs /path/to/o200k_base.tiktoken logic-report.json
```

The benchmark core ran in JavaScript, but the standalone Node CLI was not executed. See report.json. No scientific novelty claim: CNF and unsatisfiable cores are standard techniques. Independent model inference, natural-language to formula translation, external tasks and solver/tool baselines are necessary before making quality or reasoning-token claims.

Next: freeze an externally authored natural-language logic set, test semantic compilation separately from logical deduction, score answer and certificate validity, compare direct, standard CNF, ATL and solver-aided arms using actual API usage where available.
