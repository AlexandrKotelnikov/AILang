# ATL v0.5.2 — External FOLIO context reuse pilot

## Reproduce
Use Yale-LILY/FOLIO data/v0.0/folio-validation.jsonl (Git blob `06244bd10b37eac73cba7aca6c336e96011ace58`), and the official o200k_base mergeable ranks (SHA-256 checked by tokenizer).

```sh
node folio/run.mjs /path/to/o200k_base.tiktoken /path/to/folio-validation.jsonl folio-report.json
```

The benchmark function was executed in JavaScript; the standalone Node wrapper was not run. Dataset blob ID was obtained from repository metadata; the CLI checks the actual file hash. FOLIO: Han et al., EMNLP 2024, https://aclanthology.org/2024.emnlp-main.1229/.

## Main result
204 public validation examples, 73 exact shared-context groups. The conservative equal-premise-count subset has 194 examples and 69 groups. The 10 differing-count rows are identified in report.json. This check does not establish semantic equivalence; for example, the first validation row appears to have a conclusion/FOL predicate mismatch.

| Representation | All examples (tokens) | Equal-count subset |
|---|---:|---:|
| Natural language, individual | 26808 | 25209 |
| FOL, individual | 31438 | 29864 |
| Minified FOL, individual | 30687 | 29156 |
| Natural language, grouped | 11145 | 10428 |
| FOL, grouped | 13065 | 12325 |
| Minified FOL, grouped | 12747 | 12030 |
| Aliased FOL, grouped | 16522 | 15561 |
| Adaptive FOL, grouped | 14328 | 13519 |

Grouping natural language reduces static tokens by 58.43% (58.63% on subset). The best method is an ordinary grouped natural-language baseline, not a novel ATL grammar. Alias input wins only 4/73 groups; extra instruction cost eliminates the gain. All 204 grouped rows reconstruct exactly, and 146 alias roundtrips pass on all examples (two modes per group). Counts include repeated system strings and canonical JSON output, not API framing. No LLM, solver, accuracy, latency, cache or hidden reasoning measured. Gold FOL is an oracle input, not generated by ATL.

## Next experiment (proposed, not executed)
Freeze a new held-out corpus of entire premise groups, ideally independently authored and semantically audited, with FOLIO public validation as development data. Compare direct natural-language individual and grouped, gold FOL (oracle), model-generated FOL + standard prover (e.g. LINC), and ATL adaptive routes with the same answers. Fix model snapshots, decoding, budgets, retry rules, output schema and group membership before inference. Measure actual billed input/output/reasoning tokens where reported, correctness, abstention, parse failures, solver CPU time, total latency and cost including translation, tools and retries. Report paired group-bootstrap confidence intervals and cost per correct answer. Goal: beat strongest grouped baseline at a predeclared accuracy non-inferiority margin; do not claim hidden reasoning compression from text counts. Related work: Chain of Draft (https://arxiv.org/abs/2502.18600), token complexity (https://arxiv.org/abs/2503.01141), Logic-LM (https://arxiv.org/abs/2305.12295), LINC (https://aclanthology.org/2023.emnlp-main.313/). No priority or novelty claim.
